# Security Policy

## About This Repository

Personal fork of [tmux](https://github.com/tmux/tmux) with a transparent animated sixel overlay extension (GIF/PNG rendering via libpng and giflib).

## Supported Versions

Only the latest commit on `overlay-main` is actively maintained.

## Reporting a Vulnerability

To report a security vulnerability, please email **webster@webster.is**.

Do not open a public GitHub issue for security vulnerabilities.

You can expect a response within 7 days.

## Scope

This fork adds the following features on top of upstream tmux:
- Transparent animated sixel overlay (GIF/PNG rendering)
- Native PNG support via libpng
- GIF encoding via giflib

Security issues in the upstream tmux codebase should be reported to the [tmux project](https://github.com/tmux/tmux).
